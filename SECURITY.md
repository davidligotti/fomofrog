# Security policy

Last reviewed: 2026-09-03

## Scope

This repository contains token identity metadata, project links, documentation, and an image asset. It does not contain wallet private keys, signing code, custody logic, or a trading execution service.

## Reporting

Report suspected security or privacy issues privately to the repository owner through an authenticated GitHub channel. Do not publish private participant data, secrets, private keys, or exploit details in a public issue.

Include a concise description and impact, the affected file or URL, reproduction steps that do not expose secrets or personal data, and suggested remediation if known.

## Disclosure rules

- Do not claim that this repository or token has been audited unless a named independent auditor publishes a report with scope and revision or hash.
- Do not include wallet secrets, API keys, participant records, or credentials in commits or issues.
- Do not use this repository to imply liquidity, exchange approval, user counts, or investment performance.
- Security reports do not authorize token transfers, wallet signing, deployments, DNS changes, or exchange submissions.

There is currently no third-party security audit report attached to this repository.
